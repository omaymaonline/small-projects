# Duration Change Format

A small Python project that converts a duration given in seconds into **hours, minutes, and seconds**.

## What it does

The program:

1. asks the user for a duration in seconds;
2. converts it into hours, minutes, and seconds;
3. displays the result.

### Example

```text
Enter the duration in seconds: 341.5

The duration is:  0  hours,  5  minutes,  41.5  seconds.
```

## Concepts practised

* `input()`
* variables
* `float()` and `int()`
* arithmetic operators
* floor division `//`
* modulus `%`
* `round()`
* comments
* formatted output
