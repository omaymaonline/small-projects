# 🛒 Shop Calc

A small Python project that asks the user for the items in their shopping basket and their prices, then lets them view their items and calculate the total cost.

### Concepts practised

`input()` · `while loops` · `for loops` · `range()` · `isdigit()` · `try/except` · `float()` · `lists` · `append()` · `sum()` · `join()` · `lower()` · `if/else`
