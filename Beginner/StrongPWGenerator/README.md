# 🔐 Strong Password Generator

A small Python project that generates a strong password based on the number of letters, numbers, and symbols the user wants to include.

### Concepts practised

`import` · `random` · `string` · `input()` · `while loops` · `isdigit()` · `int()` · `lists` · `random.choices()` · `random.shuffle()` · `join()` · `if/else`
