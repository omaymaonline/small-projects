# 🏝️ Text Island Game

A small Python text-based adventure game built while learning conditional statements.

The player chooses a door, then follows different paths depending on their choices. The game uses:

* `if`, `elif`, and `else`
* nested conditional statements
* user input
* string methods such as `.lower()`
* integer conversion with `int()`
* multi-line strings
* ASCII art and emojis
