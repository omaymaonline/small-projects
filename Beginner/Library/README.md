# 📚 Personal Library & Wishlist

A small Python project that lets the user create a personal **book library** and **wishlist**, then update the library when a wished-for book is acquired.

### What it does

* Adds books to a personal library
* Creates a wishlist
* Checks whether a book already exists in the library or wishlist
* Allows the user to acquire a wished-for book
* Displays the library and wishlist before and after the update

### Concepts practised

`lists` · `input()` · `if / elif / else` · `in / not in` · `append()` · `lower()` · nested conditions
